# Tracker: other (Jira, Linear, Azure DevOps, ...)

Setup replaces this file with the user's own description. It must define, in prose or commands, every operation in `tracker-github.md`: **ensure-labels, create-issue, add-sub-issue, add-blocked-by, list-ready, frontier, claim, comment, set-state, close, read, selftest**, plus **map, map-frontier, resolve** for wayfinder.

Also record how the five states and the factory labels (`in-factory`, `needs-human`) map onto the tool's native statuses, and the CLI/MCP tool to use. Skills follow this file literally.
