# s_agents

A skills-and-agents kit for a ticket-driven software factory.

- **Prep (interactive):** `/setup-repo` → `/grill` or `/wayfinder` → `/to-spec` → `/to-tickets`; `/triage` for incoming issues. See `docs/kit/phase-1-prep.md`.
- **Factory (autonomous):** `/factory next` takes an unblocked `ready-for-agent` ticket through spec → build → review → approve → PR. See `docs/kit/phase-2-factory.md`.

Skills live in `.claude/skills/`, factory agents in `.claude/agents/`. Repo config is generated by `/setup-repo` into `docs/agents/`. GitHub is the default tracker; GitLab, local markdown and other trackers are alternate templates.

Not yet included: the factory dashboard and `/retro`, `/diagnose`, `/prototype`, `/research`, `/wait-what`.
